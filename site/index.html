Nine commands you will use

Plus forget to remove stored credentials.

openpub init

Create your home

Makes ~/.openpub and prints the next step.

openpub setup <platform> <json|file>

Store credentials

Saves keys to ~/.openpub/config.json with mode 0600, then verifies them.

openpub test <platform>

Check one platform

Calls the live API with the stored credentials.

openpub status

See what is reachable

Lists configured platforms with a pass or fail mark, plus your defaults.

openpub publish <file.md>

Fan out

Flags: --to, --status, --canonical, --dry-run, --force. One platform failing never stops the others.

openpub preview <file.md>

Render to HTML

Writes a local preview to ~/.openpub/preview/.

openpub frontmatter <file.md>

Rewrite frontmatter

Rewrites file in place. Supports openpub, Hugo, Jekyll, Astro, Next.js, dev.to, Hashnode, or Ghost with --format.

openpub audit <file.md>

Score the post

Flags short posts, missing headings, links, images, tags, canonical URL, and paragraphs over 60 words.

openpub check-links <file.md>

Validate URLs

Sends an 8-second HEAD request to each unique HTTP or HTTPS URL and reports results.

Three surfaces, one engine

Three interfaces for different publishing workflows.

CLI

For a terminal, a Makefile, or a cron job. Node 20 or newer. Credentials stay in local config.

npx openpub-cli publish post.md --to devto

MCP server

Runs locally over stdio. Ten tools, including x_article, so your agent can publish without leaving the editor. Keys stay in local config.

{
  "mcpServers": {
    "openpub": { "command": "npx", "args": ["-y", "openpub-mcp"] }
  }
}

GitHub Action

Runs scripts/publish.sh to publish Markdown matching the configured path. First push can publish all matching files.

- uses: princepal9120/openpub@v1
  with:
    config: ${{ secrets.OPENPUB_CONFIG }}

The platforms other tools skip

OpenPub is the only tool that ships X Articles, Substack, Ghost, and git-push in one CLI package. Pipepost and Postiz support overlapping platforms, but OpenPub combines these four with dev.to, Hashnode, WordPress, and Medium.

X Articles

Long-form to X through the Articles API with an OAuth2 user token. X Premium required.

Substack

Creates a draft through the same endpoint the web editor uses. You press publish in Substack.

Ghost

Posts through the Ghost Admin API with a custom integration key.

git-push

The github-pages adapter commits Markdown and frontmatter into your site repo.

Medium's publishing API is deprecated. The adapter still works for existing tokens and may stop without warning.

Free and MIT

No account, no credits, no telemetry. Fork it, vendor it, ship it.

  • Local CLI credentials sit in ~/.openpub/config.json, mode 0600, and go only to their own platform. Worker mode stores credentials in your own D1 database.
  • Self-host is optional. Cloudflare Worker mode uses D1, KV, R2, Queues, and Workers AI for a shared service.

  • The first successful URL becomes the canonical URL for later platforms unless frontmatter or --canonical overrides it.

Questions

What is OpenPub?

A local-first publishing CLI that takes one Markdown file and publishes it to eight platforms. It also includes an MCP server and GitHub Action.

How does authentication work?

Use openpub setup <platform> <json|file> to store credentials for that platform. Formats vary by adapter, such as an API key, integration token, or OAuth2 token.

Is my key safe?

For CLI use, OpenPub stores credentials in ~/.openpub/config.json with mode 0600 and sends them to the configured platform. Optional Worker mode stores credentials in your own D1 database.

How is OpenPub different from Pipepost or Postiz?

OpenPub is local-first and keeps credentials on your machine. The CLI supports X Articles, Substack, Ghost, and GitHub Pages.

Can I self-host it on Cloudflare?

Yes. The Worker can be self-hosted with Wrangler and a Cloudflare account. CLI works locally without the Worker.

What happens when a platform fails?

OpenPub continues publishing to other selected platforms, reports each result, and exits with an error if any platform fails.
